# Aplicación Chat App

[![hexlet-check](https://github.com/jose-lop/fullstack-javascript-project-139/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/jose-lop/fullstack-javascript-project-139/actions)

Construye una aplicación en tiempo real con React utilizando AJAX, REST, websockets, React (con hooks), Zustand, TanStack Query y @mantine/form.

Proyecto de aprendizaje de Códica: https://app.codica.la/programs/fullstack-javascript

Así debería funcionar: https://files.hexlet.app/a/t5ihxq

## Stack

- JavaScript
- React
- Vite
- Socket.IO
- Zustand
- TanStack Query
- Mantine Form

## Instalación

```bash
git clone https://github.com/jose-lop/fullstack-javascript-project-139.git
cd fullstack-javascript-project-139
npm install
```

## Uso

Para iniciar el entorno de desarrollo:

```bash
npm run dev
```

Para construir la aplicación:

```bash
make build
```

Para iniciar el servidor con la aplicación construida:

```bash
make start
```

## Pruebas automáticas de Códica

Las pruebas se ejecutan en cada commit. El archivo `.github/workflows/hexlet-check.yml` es el responsable de ejecutarlas: no lo elimine ni lo renombre, y no cambie el nombre del repositorio.
